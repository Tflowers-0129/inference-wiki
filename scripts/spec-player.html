    客户端观测 · 构造时间线

    一次输出事件，未必只有一个 token

    三个场景都输出 7 个 token。比较输出事件的间隔与整条请求的 TPOT。

      这里的“ITL”特指客户端相邻输出事件的间隔。同一次收到多个 token 时，客户端无法判断设备生成这些 token 的时间间隔。把间隔填成 0 会扭曲设备时延统计。

      如果第一条内容消息带有多个 token，客户端同样无法区分它们各自的生成时间。极端情况下，7 个 token 一块到达，按公式 TPOT 可为 0，却没有任何输出事件间隔样本；这不表示生成没有耗时。不同请求汇总时，间隔加权与请求加权也会产生差异。
